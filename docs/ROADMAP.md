# AML Insight Roadmap

## Phase 1 — Foundation
- Application shell
- FastAPI service
- Dataset preparation pipeline
- Transaction graph feature pipeline
- XGBoost baseline
- CI validation

## Phase 2 — Real-data intelligence
- IBM HI-Small ingestion validation
- Dataset profiling
- Temporal train/test split
- Leakage checks
- Calibrated transaction risk scoring

## Phase 3 — Graph intelligence
- Directed transaction graph
- Fan-in and fan-out detection
- Cycle and layering detection
- Graph embeddings
- GraphSAGE baseline
- GAT/RGCN comparison

## Phase 4 — Analyst experience
- Transaction explorer
- Account investigation page
- Interactive network explorer
- Alert queue
- Risk explanation
- Investigation cases and analyst notes

## Phase 5 — Productionization
- PostgreSQL persistence
- API pagination and filtering
- Background model jobs
- Docker deployment
- Automated tests
- Model/version metadata
- Monitoring and audit trail
